REGLAS

• Elige tu facción (5 disponibles, 8 guerreros cada una).
• Coloca tus 8 guerreros — 1 guerrero = 1 celda.
• Por turno: elige un guerrero tuyo y ataca una coordenada enemiga.
• ATK > DEF → el defensor muere instantáneamente.
• ATK = DEF → ambos mueren.
• ATK < DEF → el defensor resiste, turno perdido.
• Si atacas una celda vacía, se marca y turno perdido.
• Gana quien elimine todos los guerreros rivales.
